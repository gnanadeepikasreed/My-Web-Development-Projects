# Project 2 – Fashion Store Website

## About the Project
The Fashion Store Website is designed to display the latest fashion trends, clothing collections, and accessories. It helps customers explore clothing categories, view product images, check prices, and discover special offers.

## Technologies Used
- HTML
- CSS

## Main Features
- Navigation bar
- Attractive clothing images
- Different clothing categories
- Product cards with prices
- Special offers and discounts
- Featured fashion collections
- User-friendly layout

## Project Output
The website was successfully developed and opened in a web browser.
