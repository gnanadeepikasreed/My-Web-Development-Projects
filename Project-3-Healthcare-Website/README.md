# Project 3 – Hospital & Healthcare Website

## About the Project
The Hospital and Healthcare Website is designed to provide information about hospital facilities, medical departments, doctors, and healthcare services. It helps patients explore medical services, view doctor profiles, book appointments, and find emergency contact details.

## Technologies Used
- HTML
- CSS

## Main Features
- Navigation bar
- Hospital information
- Medical departments
- Doctor profiles
- Medical services
- Appointment booking section
- Health information
- Emergency contact details
- User-friendly layout

## Project Output
The website was successfully developed and opened in a web browser.
